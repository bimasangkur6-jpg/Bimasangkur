# Portofolio — Bima Sangkur

Website portofolio statis (HTML, CSS, JavaScript murni, tanpa framework/build tool).

## Struktur folder

```
portfolio-website/
├── index.html          ← struktur halaman (sidebar nav, hero, about, skills, projects, contact)
├── css/
│   └── style.css       ← semua styling
├── js/
│   └── script.js       ← interaksi (menu mobile, scroll reveal, scrollspy nav, scroll progress bar)
├── images/              ← background & gambar proyek
└── assets/
    └── icons/           ← favicon
```

## Cara melihat hasilnya

Klik dua kali `index.html`, atau buka lewat browser. Tidak perlu server/instalasi apa pun.

## Kontak

Section "Contact" cuma link `mailto:` biasa ke email — nggak ada form, jadi nggak perlu setup layanan pengiriman email apa pun.

## Deploy (gratis)

- **Netlify Drop**: [app.netlify.com/drop](https://app.netlify.com/drop) — drag & drop folder ini
- **Vercel**: `vercel deploy`
- **GitHub Pages**: push ke repo GitHub, aktifkan di Settings → Pages
